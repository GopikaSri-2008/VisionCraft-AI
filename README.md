# 🎨 VisionCraft-AI

VisionCraft-AI is a simple AI image generator web application that creates images from text prompts.

## ✨ Features

- 📝 Text prompt input
- 🖼️ AI image generation
- 👀 Image preview
- ⬇️ Download generated image
- 📱 Responsive design
- 🎨 Clean and simple interface

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Python
- Flask
- AI Image Generation API
